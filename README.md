# StudyNote

StudyNote 是一个把 PDF 教材整理成学习笔记的 Windows 电脑软件。你可以阅读教材、自己写笔记，也可以配置 AI 帮忙整理，最后把笔记导出保存。教材和笔记保存在自己的电脑上。

## 普通用户使用教程

第一次使用，建议先试“打开软件 → 导入一本教材 → 自己写一条笔记 → 保存”。这几步不需要配置 AI。

### 1. 直接打开软件

1. 按住键盘上的 **Windows 标志键**，再按 **E**，打开文件管理窗口。点击窗口顶部的地址栏，输入 **`D:\StudyNote`**，再按回车。
2. 找到 **StudyNote.exe**，连续点击两次，就会打开软件，不需要先安装。文件夹里的 **使用说明.txt** 也可以双击阅读。
3. 第一次看到欢迎窗口时，点击 **先离线使用**，就可以开始阅读、写笔记和导出。以后也能随时配置 AI。

**请保留整个 StudyNote 文件夹。** 其中的 `studynote-backend.exe` 是软件需要的后台文件，打开 StudyNote.exe 时会自动使用它。给别人复制软件时，也要复制整个文件夹。学习资料另存于本机用户目录，换电脑前请在软件里备份资料。

如果希望安装后从 **开始菜单** 打开，可以进入 **`D:\StudyNote\installers`** 文件夹，双击 **StudyNote_0.2.0_x64-setup.exe**，按提示完成安装。安装时保持联网，可能需要下载运行组件。项目源码放在 `D:\pdf分割`；日常使用只需打开 `D:\StudyNote`。

### 2. 放入自己的教材

1. 点击软件左边的 **我的教材**，再点击 **导入教材**。
2. 在弹出的文件窗口中找到自己的 PDF 教材，选中它，点击“打开”。PDF 文件的名字通常以 `.pdf` 结尾。
3. 在 **课程名称** 中填一个容易记住的名字，例如“电路基础”，然后点击 **确认导入**。

看到教材卡片和底部“教材已导入”，就说明成功了。软件会复制教材，原来的 PDF 保持原样。

### 3. 阅读并选出一个小章节

1. 点击教材卡片上的 **阅读与分章**，用页面上方的左右箭头翻页。
2. 在右边填写 **章节名称**、**起始页**、**结束页**。第一次先选很小的范围，例如“第一章”，从第 1 页到第 2 页。
3. 点击 **拆分并提取文字**，然后在“已拆分章节”中点击这个章节，展开 **核对提取文字**，检查文字是否正确。

这里的页码从 PDF 的第一页开始数，**包含封面和目录**。请以软件显示的页码为准，书上印的“第 1 页”可能是 PDF 的第 8 页。

### 4. 自己写笔记（不使用 AI 也可以）

1. 点击左边的 **我的笔记**，再点击 **新建笔记**。
2. 填写 **笔记标题**，在下面的正文区域直接打字。保持默认的 **富文本** 模式即可，工具栏的“加粗”“项目列表”等按钮可按需要使用。
3. 点击 **保存笔记**，看到底部“笔记已保存”后再离开。**以后每次改完内容，也要再点一次保存。**

想分类时，在 **知识主题** 中填写“电路基础, 欧姆定律”这样的内容，用逗号分隔并保存；再点击左边的 **知识体系**，就能按主题找笔记。在“我的笔记”的 **搜索笔记** 框中输入关键词，也能查找正文。

### 5. 让 AI 整理章节（可选）

1. 点击左边的 **AI 与模型**，把自己的 **API Key** 填入对应输入框，点击 **保存配置**。API Key 是 AI 服务商给你的专用密钥，需要从自己的服务账号获取；不会获取时可以请熟悉的人协助配置。地址、模型和单价也要与该服务商提供的信息一致。
2. 回到 **阅读与分章**，在“已拆分章节”中选中要整理的章节，点击 **生成章节笔记**。
3. 查看弹出的文字内容和预计费用。确认愿意把这些文字发送给 AI 服务商，再点击 **确认生成**；不想发送就点击“取消”。如果提示已有内容，点击 **使用缓存** 即可复用。
4. 等待底部提示生成完成，软件会自动保存结果并打开“我的笔记”。自己再修改后，仍需点击 **保存笔记**。

AI 生成以及“验证已保存的主模型”可能产生服务商费用，窗口中的费用是美元估算。手写笔记、阅读和导出不调用 AI。AI 内容请对照教材检查后再用于学习。

### 6. 把笔记带走，给资料留一份备份

- **带走笔记：** 点击左边的 **备份与导出** → **选择导出位置**，选一个方便找到的文件夹，例如桌面。完成提示会告诉你具体位置；里面的笔记文件可以用文本编辑软件打开，也可以在 Obsidian 中使用。不需要先安装 Obsidian 才能导出。
- **保留全部资料：** 在同一页点击 **创建完整备份**，选择保存位置，保留生成的 `.zip` 文件。它包含教材、章节和笔记数据。建议学习一段时间后备份一次，重要备份另存一份到其他硬盘或 U 盘。

本版本还没有“一键恢复”按钮。需要恢复时，请保留好 ZIP 文件并找熟悉电脑的人协助；AI 密钥不在备份里，换电脑后要重新配置。

### 常见问题

- **能看 PDF，但提取不到文字：** 可能是扫描教材，也就是每页是一张图片。目前可以阅读、分章和手写笔记，但无法自动识别图片文字；请换用能提取文字的 PDF，或先用其他工具识别图片文字（称为 OCR）。
- **不知道资料存在哪里：** 打开 **备份与导出**，查看页面下方的 **当前资料保存位置**。平时直接在软件里操作即可。
- **关闭时提示有未保存内容：** 点击“取消”留在当前页面，再点击 **保存笔记**。
- **试卷分析还不能用：** 这是后续功能入口，目前先使用教材和笔记功能。
- **其他电脑打开时提示缺少 WebView2：** 这是软件显示界面所需的系统组件，请使用安装版按提示补齐，或请提供软件的人协助。

## 已实现

- 首次引导、学习首页、教材导入、PDF 页面阅读、书签提示和按页分章。
- 主模型与可选第二模型、Windows 系统凭据管理器保存 Key、发送前预览、预算、缓存与后台生成。
- Tiptap 富文本和 Markdown 原文编辑、历史版本恢复、跨教材主题聚合与 SQLite FTS5 搜索。
- Obsidian 导出、ZIP 备份、旧版数据库自动备份和升级。

试卷分析页面按规划保留为后续入口。OCR、语义检索、知识图谱、备份恢复向导、自动更新和发布签名尚未实现。

## 开发者说明：环境与启动

以下命令供维护或开发软件的人使用；普通用户双击上述程序即可。技术栈为 **React + TypeScript + shadcn/ui + Tailwind CSS + Tiptap + Tauri 2 + Python Sidecar + PyMuPDF + SQLite FTS5**。当前仓库即 StudyNote 项目根目录。

Windows 10/11 x64，Node.js 24、pnpm 11.25、Python 3.14、Rust stable、Visual Studio C++ Build Tools、WebView2。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-build.txt
pnpm install --frozen-lockfile
pnpm dev
```

浏览器开发界面：http://127.0.0.1:1420 。开发模式使用路径输入框替代原生文件对话框。先执行 `pnpm build:sidecar`，再用 `pnpm dev:desktop` 启动真正的桌面窗口。双击 run.bat 启动浏览器开发模式。

```powershell
pnpm check          # 后端、迁移、前端单测、类型和生产构建
pnpm test:e2e       # Edge 中的完整离线业务流程
pnpm build:portable # 检查、打包直接启动版并从发布目录验证
pnpm build:installer # 将已生成并验证的程序封装为安装包
pnpm build:desktop  # 先生成并验证直接启动版，再封装安装包
```

目标电脑无需安装 Python 或 Node.js，需要 WebView2。安装版可联网获取缺少的运行组件。输出位置见 [Windows 构建](docs/release/windows.md)。

发布文件放在源码目录以外：本机直接启动版为 `D:\StudyNote\StudyNote.exe`，后台文件和使用说明与它放在一起；安装包为 `D:\StudyNote\installers\StudyNote_0.2.0_x64-setup.exe`。默认使用项目旁边的 StudyNote 文件夹，也可用 STUDYNOTE_RELEASE_DIR 指定外部目录。构建会先验证外部目录中的程序，再封装安装包；生成的安装包会移出源码目录，旧的根目录安装包也会清理。

修改代码后先重新运行 build:portable，再运行 build:installer；build:desktop 会按顺序完成两步。直接启动验证以发布文件夹为工作目录，清除项目的 Python 导入路径，用绝对路径保存测试报告。

安装包封装前会用 SHA256 核对实际打包的主程序和后台文件是否与已验证的直接启动版一致；文件不同或缺失时停止并提示重新生成。封装时保留主程序原有字节，保证使用的是同一组已验证程序。

直接启动构建会明确把已打包的后台程序放到主程序旁边，因此首次构建也无需依靠旧安装包留下的文件。

## 数据与隐私

直接启动版与安装版都默认使用 `%LOCALAPPDATA%\StudyNote`；检测到旧版 `%LOCALAPPDATA%\StudyDesk\study.sqlite3` 时沿用旧目录。可用 STUDYNOTE_DATA_DIR 指定隔离目录。导入复制原文件，不改写教材。仅在确认 AI 请求后发送预览文本。Key 不进入前端响应、日志或 ZIP 备份。

API Key 保存在当前 Windows 用户的系统凭据管理器，每个工作区使用独立凭据。旧版 DPAPI 文件首次读取时自动迁移，系统保存成功后删除旧文件。数据库 v1/v2 自动备份并升级至 v3，重建已有笔记的 FTS5 索引。

费用使用可编辑的美元单价与保守 UTF-8 估算，不能替代服务商账单；请按实际账户更新配置。超时或未知计费保留预估费用，避免无限重试。
