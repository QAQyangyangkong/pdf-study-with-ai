# 项目架构与 MVP 范围

## 已读取的需求

来源：用户引用的「MVP功能规划」聊天中的用户消息。

1. 完全独立桌面软件，支持 Obsidian 导出。
2. 将大 PDF 教材按章节分割，再用 AI 生成可按需要调整的笔记，优先节省调用费用。
3. 支持跨教材笔记组织，形成知识体系。
4. 支持多年试卷 PDF、Word、图片的考点和考情分析。
5. 使用者自行配置 API Key，1 到 2 个模型，可用默认推荐或手动选择；优先 DeepSeek。
6. 普通办公用户可以操作；MVP 通过安装包分发，后期才建设自动更新服务器。

技术栈和阶段划分是本次实现的选择，无法核对引用聊天助手回复中被占位符替代的设计内容。

## 实现结构

```text
src/study_desk/
  __main__.py     启动参数、桌面入口、启动冒烟验证
  app.py          四个原生桌面工作页与后台任务队列
  workspace.py    服务组合、数据库与文件一致性备份
  config.py       模型、单价、预算与目录配置
  db.py           SQLite 表、版本号、主题关系、缓存和费用记录
  documents.py    PDF/DOCX/TXT 导入、书签、章节拆分与文字提取
  ai.py           Chat Completions 适配、提示词、缓存和预算检查
  security.py     Windows DPAPI 加密密钥存储
  export.py       Markdown、来源和 Obsidian 主题索引
tests/           业务边界、模拟 AI、Windows 密钥、桌面流程测试
scripts/         测试与构建入口
packaging/       PyInstaller 配置与 Inno Setup 安装脚本
docs/            范围、架构、验证与后续路线
```

界面采用 Python 标准库 Tkinter/ttk，持久化采用 SQLite，PDF 处理采用 pypdf；网络使用标准库 HTTPS 客户端。运行时外部 Python 依赖只有 pypdf，利于当前雏形开发和 Windows 打包。UI、持久化与文档/AI 服务分开，后续可以替换 UI 框架。

所有缓慢操作在一个后台工作线程执行；只有主线程操作 Tk 控件。SQLite 每次操作创建独立连接，事务结束显式关闭。数据库保存相对文件路径，便于备份迁移。

## 数据流

```text
本地教材 → 校验与内容哈希 → 托管副本 → 书签建议 / 手工页码
         → 章节 PDF + 带原始页码文字 → 人工核对
         → 模型/偏好/费用预览 → 缓存检查 → 预算预留 → AI 请求
         → 笔记正文 + 材料来源 → 人工编辑与知识主题 → Obsidian 导出

历年试卷 → 课程与年份 → 文字提取 → 选择同课程材料
         → 内容与估算预览 → AI 考点报告 → 笔记库
```

输入材料不会整本自动发送。请求缓存键包括地址、模型、系统提示、偏好、正文及输出限制；价格与每日预算不影响已生成文本的复用。HTTPS 重定向禁用以避免转发密钥。失败与不完整响应不缓存，网络不会自动重试。

知识主题是显式笔记关联，目前没有自动同义词合并或知识图谱。考点频次是 AI 的材料内分析，尚未建立人工校正的结构化题目/考点统计库。

## 本地数据与版本

```text
%LOCALAPPDATA%/StudyDesk/
  study.sqlite3        文档、章节、笔记、主题、配置、缓存、费用
  api-key.dpapi        当前 Windows 账号加密后的 API Key
  documents/           导入文件托管副本
  chapters/            拆分后的 PDF
```

数据库目前只有 schema v1，通过 `PRAGMA user_version` 管理。初次建表与版本写入使用同一事务；遇到较新数据库版本拒绝打开，避免旧程序破坏新数据。目前没有 v1→v2 迁移，因为还没有第二版 schema。

备份使用 SQLite backup API，打包数据库与文件，省略密钥。UI 限制任务串行，备份时不允许导入或拆分。备份恢复目前为人工操作：关闭软件，将 ZIP 解压到一个新目录，用 `--data-dir` 指向该目录，核对资料后重新配置 Key。不要直接覆盖正在使用的目录。

## 分发与后续阶段

当前提供可验证的 PyInstaller 便携版和 Inno Setup 安装脚本。安装在当前用户 Programs 目录，无需管理员权限；卸载不删除个人学习数据。覆盖升级先备份，用户手动下载新版。

下一阶段：OCR 任务与结果校对、章节长文本分块和分层总结、笔记生成与修订版本、结构化考点/题目/年份统计、统一课程知识主题管理、导出附件与来源跳转。

正式发布阶段：UI 与易用性验收、崩溃恢复、取消/进度、数据库迁移备份与回滚、代码签名、安装/覆盖升级/卸载验证。拥有服务器之后，再增加签名更新清单、后台下载、版本兼容校验、备份后迁移及失败回滚；当前不接入伪造更新服务。
