# MVP 范围

核心流程：教材导入 → 阅读与分章 → 预览并确认 AI 请求 → 生成笔记 → 编辑 → 知识主题 → 导出。

首次引导允许离线使用。首页显示真实计数。教材按标题或课程过滤；阅读页显示实际 PDF 页码，书签辅助填写分章范围，由用户确认。扫描件不虚构文字，提示需要 OCR。

AI 预览冻结材料、模型、端点和价格，确认后后台生成。缓存命中不调用服务商。笔记保留教材和 PDF 页码来源，支持手动主题、版本恢复与跨笔记关联。知识主题是笔记聚合，未做自动知识点归并或关系推断。

笔记默认使用 Tiptap 富文本编辑，可直接加粗、设置标题和列表，按需切换 Markdown 原文或阅读预览。SQLite 保存 Markdown 而非 HTML，AI 输出、版本记录和 Obsidian 导出沿用同一内容格式。笔记搜索调用本地 FTS5 服务，短查询仍可查到中文词组。

包含公式、Obsidian 双链、脚注、HTML 或 YAML 元数据的笔记会保留在 Markdown 原文模式，避免富文本转换丢失内容。普通笔记支持标题、列表、表格、任务项、链接和代码块；只切换视图不会改写原文或产生未保存状态。

试卷分析、OCR、语义检索、图谱、恢复向导和更新器为后续阶段。后端保留旧版试卷适配代码，本次桌面界面不暴露试卷分析流程。真实模型质量和账户计费需另行使用有效 Key 验证。
